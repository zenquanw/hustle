## 目录

```
projects/   每个作品一个文件夹，内含 README.md
assets/     截图、图片等素材
```

## 添加新作品

1. 在 `projects/` 下新建文件夹，例如 `projects/first-work/`
2. 写一份 `README.md`：解决什么问题、怎么运行、效果截图
3. 回到本页「作品列表」补一行
4. 提交：

```bash
git add .
git commit -m "add: 新作品"
git push
```
